# COGSCI 200 Flashcards

期末复习用的 flashcard——基于 Winter 2026 全部 24 份 lecture slides + Exam 1/2 Reviews + Final Review I 做成。

## 怎么用

- 点卡片翻面 / tap to flip
- ← → 上一张下一张（手机可以左右滑）
- 可以按 topic 筛选（Cross-cutting / Perception / Language / Rationality 等）
- "会了/再看" 标记会存在本地
- 手机和电脑都能用

## 特点

- 术语英文（考试是英文的）
- 解释中英夹杂，够用就行
- 深色主题，手机看眼睛舒服

## 内容范围

涵盖所有考点：Marr 三层、Dual processes、Bayes' Rule、POS argument、Modularity、4 个 language properties、UG、CTM、Turing Machine、4 takes on emotion (LeDoux)、4 takes on rationality、4 heuristics (representativeness/availability/affect/framing)、Q-learning、Iowa Gambling Task、Trolley problems、DDE、Greene vs Mikhail...

人物、实验、公式、Exam Review 答案全都在。
